# SMEasy auth emails

Generated by `node scripts/build-email-templates.mjs`. Edit the script, not the HTML.
Open `preview.html` in a browser to see them.

Paste each into **Supabase → Authentication → Emails → Templates**:

| Supabase template | File | Subject |
|---|---|---|
| Magic Link | `magic-link.html` | Your SMEasy login link |
| Confirm signup | `confirm-signup.html` | Welcome to SMEasy: confirm your email |
| Reset Password | `reset-password.html` | Reset your SMEasy password |
| Change Email Address | `change-email.html` | Confirm your new SMEasy email address |
| Reauthentication | `reauthentication.html` | Your SMEasy verification code |

SMEasy uses login links (no passwords), so **Magic Link** and **Confirm signup** are the ones people actually get.
Sender (SMTP settings): `SMEasy <hello@smeasy.au>` via Resend.
